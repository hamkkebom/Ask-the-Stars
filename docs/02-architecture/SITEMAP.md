## � 플랫폼 비전

**"150명+ AI 영상 제작 프리랜서가 콘텐츠를 만들고, 관리자가 품질을 관리하며, 완성된 영상을 넷플릭스처럼 보여주는 B2B 영상 제작 플랫폼"**

---

## �🏗️ 전체 사이트 구조

```txt
🏠 함께봄 (hamkkebom.com)
│
├── 🎬 영상 갤러리 (메인)            → /videos/        ← 방문자
├── ⭐ 프리랜서 대시보드             → /stars/         ← 프리랜서
├── 🛠️ 관리자 대시보드              → /admin/         ← 운영팀
└── 🔐 인증                          → /auth/          ← 모든 사용자
```

> ⚠️ **메인 페이지**: `/` 접속 시 `/videos/`로 리다이렉트

---

## � 핵심 워크플로우

```txt
[클라이언트 의뢰] → [관리자 접수]
                        ↓
               [프리랜서 배정]
                        ↓
          [프리랜서] → 제작 → 업로드
                        ↓
               [관리자 검수/승인] ←── 핵심!
                    ↓       ↓
          [영상 갤러리 공개]  [프리랜서 정산]
                ↑              ↓
           방문자 시청      💰 지급 처리
```

> ⚠️ **중요**: 관리자 승인 후에만 영상 공개 + 정산 처리

## 🎬 1. 영상 갤러리 (메인)

> **대상**: 모든 방문자  
> **목적**: 넷플릭스 스타일 영상 탐색

| 경로 | 페이지명 | 역할 |
|------|----------|------|
| `/videos/` | 영상 갤러리 | 전체 영상 그리드, 검색, 필터 |
| `/videos/{id}/` | 영상 상세 | 플레이어, 메타데이터, 관련 영상 |
| `/videos/category/{slug}/` | 카테고리별 | 특정 카테고리 영상만 표시 |

## ⭐ 2. 프리랜서 대시보드

> **대상**: 로그인한 프리랜서  
> **목적**: 제작, 업로드, 수입 관리

### 2.1 메인 & 분석

| 경로 | 페이지명 | 역할 |
|------|----------|------|
| `/stars/` | 대시보드 | 요약 카드, 알림, 빠른 액션, 성과 그래프 |
| `/stars/dashboard/` | 대시보드 메인 | 대시보드 메인 뷰 |
| `/stars/dashboard/analytics/` | 상세 분석 | 트렌드 분석, 인구통계, 리포트 다운로드 |

### 2.2 프로젝트 관리

| 경로 | 페이지명 | 역할 |
|------|----------|------|
| `/stars/project-board/` | 제작요청 게시판 | 수주 가능한 의뢰 목록 (오픈 프로젝트 포함) |
| `/stars/open-projects/` | 오픈 프로젝트 | 공개된 프로젝트 목록 |
| `/stars/my-projects/` | 내 프로젝트 | 내가 참여 중인 프로젝트 |
| `/stars/my-projects/detail/{id}/` | 프로젝트 상세 | 의뢰 상세, 진행 관리 |
| `/stars/request-detail/{id}/` | 요청 상세 | 제작 요청 상세 보기 |
| `/stars/requests/create/` | 요청 생성 | 새 제작 요청 생성 |

### 2.3 영상 관리

| 경로 | 페이지명 | 역할 |
|------|----------|------|
| `/stars/upload/` | 영상 업로드 | 드래그앤드롭, 메타데이터 입력, 썸네일 |
| `/stars/direct-upload/` | 직접 업로드 | Cloudflare Stream 직접 업로드 |
| `/stars/my-videos/` | 내 영상 목록 | 업로드한 영상, 상태별 필터 |

### 2.4 피드백 & 수입

| 경로 | 페이지명 | 역할 |
|------|----------|------|
| `/stars/feedback/` | 받은 피드백 | 피드백 목록, 수정 요청 확인 |
| `/stars/earnings/` | 수입 관리 | 정산 내역, 정산 요청, 세금계산서 |
| `/stars/work-journal/` | 작업 일지 | 일일 작업 기록, 진행 상황 보고 |

### 2.5 프로필 & 설정

| 경로 | 페이지명 | 역할 |
|------|----------|------|
| `/stars/performance/` | 내 성과 | 완료율, 평점, 순위, 배지 |
| `/stars/profile/` | 내 프로필 | 공개 프로필 편집 |
| `/stars/portfolio/` | 포트폴리오 | 대표작 선정, 포트폴리오 구성 |
| `/stars/settings/` | 설정 | 알림, 계정, 정산 계좌 |
| `/stars/resources/` | 자료실 | 템플릿, 가이드, 브랜드 에셋 |
