# 🗺️ 로드맵 (Roadmap)

> **문서 버전**: 2026-01-30
> **플랫폼 비전**: 영상 갤러리 + 프리랜서 + 관리자

---

## 📅 함께봄 2.0 로드맵

### 1단계: 핵심 MVP 완료 ✅

**핵심**: 영상 갤러리 + 프리랜서(Stars) + 관리자(Admin)

| 항목 | 상태 | 비고 |
|------|:----:|------|
| 모노레포 아키텍처 | ✅ | Next.js 15 + NestJS 11 |
| 영상 갤러리 | ✅ | 넷플릭스 스타일 UI |
| 프리랜서 대시보드 | ✅ | 업로드/수정/정산 |
| 관리자 대시보드 | ✅ | 검수/승인/정산 |
| 인프라 배포 | ✅ | Cloud Run + Vercel + R2/Stream |

---

### 2단계: 영상 관리 고도화 (2026.Q1)

**핵심**: 프리랜서 자율 영상 관리 + 자동 메타데이터

| 항목 | 상태 | 설명 |
|------|:----:|------|
| 프리랜서 영상 수정 | 🔄 | 제목/설명/태그/썸네일/파일교체 |
| 자동 메타데이터 수집 | 🔄 | 해상도/길이/크기 자동 추출 |
| 버전 히스토리 | ⬜ | 영상 교체 이력 관리 |
| 카테고리별 갤러리 | ⬜ | `/videos/category/{slug}/` |

---

### 3단계: 운영 효율화 (2026.Q2)

**핵심**: 활동 로그 + 워크플로우 자동화

| 항목 | 상태 | 설명 |
|------|:----:|------|
| 활동 로그 | ⬜ | `/admin/activity-log/` |
| 작업 일지 | ⬜ | 프리랜서 진행 보고 |
| 자동 알림 | ⬜ | 승인/반려/정산 알림 |
| 정산 자동화 | ⬜ | 승인 즉시 정산 트리거 |

---

### 4단계: 확장 (2026.Q3~)

| 항목 | 설명 |
|------|------|
| 클라이언트 포털 | 의뢰 생성 → 진행 확인 → 결과물 수령 |
| 자동 매칭 | 프로젝트-프리랜서 AI 매칭 |
| 다국어 | 영문/일문 지원 |

---
