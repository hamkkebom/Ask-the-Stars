# 📖 사용자 가이드 (함께봄)

> **문서 버전**: 2026-01-29
> **플랫폼 비전**: 영상 갤러리 + 프리랜서 + 관리자

이 가이드는 함께봄 플랫폼의 주요 기능 사용 방법을 안내합니다.

---

## 🎬 영상 갤러리 (방문자)

모든 방문자는 고품질 AI 영상을 탐색할 수 있습니다.

| 기능 | 경로 | 설명 |
|------|------|------|
| 영상 갤러리 | `/videos/` | 전체 영상 검색/필터 |
| 영상 상세 | `/videos/{id}/` | 영상 재생, 상세 정보 |
| 카테고리별 | `/videos/category/{slug}/` | 특정 카테고리 영상 |

---

## ⭐ 프리랜서 (Stars)

등록된 프리랜서 전용 대시보드 사용법입니다.

### 1. 프로젝트 수주

1. `제작요청 게시판` (`/stars/project-board/`)에서 의뢰를 탐색합니다.
2. 마음에 드는 프로젝트를 선택하고 상세 내용을 확인합니다.
3. **수락** 버튼을 클릭하여 프로젝트에 참여합니다.

### 2. 영상 제작 & 업로드

1. 프로젝트 요구사항에 맞게 영상을 제작합니다.
2. `/stars/upload/`에서 영상을 업로드합니다.
3. 제목, 설명, 태그, 썸네일을 입력합니다.

### 3. 영상 관리

`/stars/my-videos/`에서 업로드한 영상을 관리합니다.

| 기능 | 설명 |
|------|------|
| 제목/설명 수정 | 기본 정보 변경 |
| 썸네일 변경 | 새 이미지 업로드 |
| 파일 교체 | 새 영상 파일로 대체 |
| 메타데이터 조회 | 해상도, 길이, 크기 확인 |

### 4. 수입 관리

`/stars/earnings/`에서 정산 내역을 확인합니다.

> ⚠️ **중요**: 관리자 승인 후에만 정산이 진행됩니다.

## 🛠️ 관리자

운영팀 전용 기능입니다.

### 핵심 워크플로우

```
의뢰 접수 → 프리랜서 배정 → 제출물 검토 → 승인
                                        ↓
                            영상 공개 + 정산 처리
```

### 주요 기능

| 경로 | 역할 |
|------|------|
| `/admin/` | 통합 대시보드 |
| `/admin/videos/` | 영상 자산 관리 |
| `/admin/stars/` | 프리랜서 관리 |
| `/admin/stars/reviews/` | 제출물 검토/승인 |
| `/admin/finance/` | 재무/정산 |
